Discord Music BOT

Discord用
音楽BOT。

sanzyo musicは、YouTube・ニコニコ動画・Spotifyなど多彩なサービスに対応したDiscord音楽BOTです。高音質で、シンプルに。

Features

01

多サービス対応

YouTube、ニコニコ動画、Spotify、Discordの音声ファイルなど、幅広いソースから音楽を再生できます。

02

プレイリスト再生

YouTubeのプレイリストやSpotifyのアルバム・プレイリストをそのままキューに追加。まとめて楽しめます。

03

イコライザー

低音強化・中音強化・高音強化の3モードを搭載。好みの音質に合わせて細かく調整できます。

04

ループ再生

1曲ループとプレイリストループに対応。繰り返し聴きたい曲も、アルバムごとループも自在です。

05

自動退出

ボイスチャンネルに誰もいなくなると、10秒後に自動で退出します。無駄な接続を残しません。

06

高音質ストリーミング

最大256kbpsのビットレートで高音質再生。loudnormフィルターで音量も自動で最適化されます。

07

MIDI再生

FluidSynthを使ってMIDIファイルをリアルタイムに変換して再生。GS・GM・FC・SC-88など多彩なSoundFontに対応。

08

時報

毎時正時に予鈴・本鈴を自動で鳴らします。チャンネルを選ばず、s!zihouコマンドで簡単に起動できます。

Commands

コマンド
一覧。

コマンド 説明
s!play <URL / キーワード>
s!p
 URLまたはキーワードで音楽を再生・検索します。プレイリスト・MIDIファイルにも対応。
s!skip
s!s
 現在再生中の曲をスキップして次の曲へ進みます。
s!stop
 再生を停止してキューをクリアします。
s!leave
 ボイスチャンネルから退出します。
s!queue
 現在のキュー（待ち曲一覧）を表示します。
s!loop
 現在の曲を1曲ループします。もう一度実行するとOFFになります。
s!mloop
 プレイリスト全体をループします。もう一度実行するとOFFになります。
s!eq <0–3>
 イコライザーを変更します。0:通常 / 1:低音強化 / 2:中音強化 / 3:高音強化
s!sf
 MIDIファイル再生に使用するSoundFontを選択します。
s!zihou
 毎時正時チャイムを開始します。予鈴（523Hz）×3 → 本鈴（1046Hz）。s!zihou stop で停止。
s!help
 コマンド一覧を表示します。
